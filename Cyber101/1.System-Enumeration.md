# System Enumeration and Device Information Gathering

## Objective

Learn how to collect hardware and operating system information from a Windows endpoint using various system information tools.

## Tools Used

- HWiNFO64
- System Information (msinfo32)
- Task Manager
- Command Prompt

## Information Collected

- CPU Information
- Memory Configuration
- Storage Devices
- GPU Information
- Motherboard Information
- Operating System Version
- Secure Boot Status
- TPM Status

## Key Findings

- Successfully identified hardware specifications.

## Lessons Learned

Understanding system information is important for troubleshooting, asset management, vulnerability assessment, and security investigations.
