# Defense in Depth

## Overview
Defense in Depth is a cybersecurity strategy that applies multiple layers of security controls to protect systems, applications, networks, and data. The objective is to reduce the risk of compromise by ensuring that if one security layer fails, additional controls remain in place.

## Layer 1: Security Policy & User Awareness
Security awareness training, acceptable use policies, password policies, and secure development guidelines.

**Mitigates:**
- Social Engineering
- Phishing
- Human Error

---

## Layer 2: Physical Security
Physical protection of facilities and critical assets through access control systems, CCTV, security personnel, and environmental monitoring.

**Mitigates:**
- Unauthorized Physical Access
- Equipment Theft
- Environmental Threats

---

## Layer 3: Perimeter Security
Protection at the network perimeter using technologies such as firewalls, web application firewalls (WAF), intrusion detection and prevention systems (IDS/IPS), and DDoS protection.

**Mitigates:**
- SQL Injection
- Cross-Site Scripting (XSS)
- DDoS Attacks

---

## Layer 4: Network Security
Network segmentation, VLANs, Network Access Control (NAC), and internal traffic monitoring to limit lateral movement.

**Mitigates:**
- Lateral Movement
- Unauthorized Internal Access

---

## Layer 5: Endpoint Security
Protection of endpoints using antivirus solutions, EDR, patch management, and host-based security controls.

**Mitigates:**
- Malware
- Ransomware
- Known Vulnerabilities

---

## Layer 6: Application Security
Secure SDLC practices including code review, security testing, input validation, and penetration testing.

**Mitigates:**
- SQL Injection
- XSS
- Command Injection

---

## Layer 7: Data Security
Data encryption, backup strategies, data classification, and Data Loss Prevention (DLP) controls.

**Mitigates:**
- Data Leakage
- Data Theft
- Unauthorized Disclosure

---

## Layer 8: Identity & Access Management (IAM)
User authentication and authorization through MFA, RBAC, SSO, and least-privilege principles.

**Mitigates:**
- Account Takeover
- Privilege Escalation
- Unauthorized Access

---

## Layer 9: Monitoring & Incident Response
Continuous monitoring through SIEM, log analysis, threat detection, and incident response processes.

**Mitigates:**
- Advanced Persistent Threats (APT)
- Data Breaches
- Security Incidents

---

## Key Learning Outcomes
- Understanding layered security architecture.
- Applying defense-in-depth principles to enterprise environments.
- Mapping security controls to attack techniques.
- Strengthening security monitoring and incident response capabilities.
