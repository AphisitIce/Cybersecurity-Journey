# SOC Model

## Overview

The Security Operations Center (SOC) is responsible for continuously monitoring, detecting, analyzing, and responding to cybersecurity threats within an organization.

A SOC helps improve an organization's security posture by combining people, processes, and technology to identify and respond to security incidents.

---

## Core Components

### People

Security professionals responsible for monitoring, investigating, and responding to security events.

Examples:

- SOC Analyst
- Security Engineer
- Incident Responder
- Threat Hunter

---

### Process

Standardized procedures used to handle security events and incidents.

Examples:

- Monitoring
- Alert Management
- Incident Triage
- Incident Response
- Reporting

---

### Technology

Tools used to collect, analyze, and respond to security events.

Examples:

- SIEM
- Vulnerability Scanners
- Endpoint Security Solutions
- Threat Intelligence Platforms

---

## SOC Workflow

1. Collect Logs
2. Monitor Events
3. Detect Threats
4. Investigate Alerts
5. Respond to Incidents
6. Recover Systems
7. Improve Security Controls

---

## SOC Analyst Responsibilities

- Monitor security alerts
- Analyze log data
- Investigate suspicious activities
- Escalate incidents
- Document findings
- Support incident response activities
