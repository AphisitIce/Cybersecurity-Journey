# SOC Lab Environment Setup

## Overview

This lab environment was built to simulate a basic Security Operations Center (SOC) for learning security monitoring, log collection, event analysis, and threat detection using Splunk.

The environment consists of multiple virtual machines running Windows and Linux operating systems within VMware Workstation. Logs are forwarded to Splunk Enterprise through Splunk Universal Forwarder, enabling centralized monitoring and analysis through the Splunk Web interface.

## Lab Components

### Virtual Machines

- Windows 7
- CentOS 6
- Kali Linux
- Metasploitable2

### Security Tools

- Splunk Enterprise
- Splunk Universal Forwarder
- VMware Workstation
